This project serves a locally mirrored export of `https://radge.framer.website` through Next.js so the site can run independently from Framer.

## Getting Started

First, regenerate the mirrored assets when needed:

```bash
node scripts/download-assets.mjs
```

Then run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the mirrored site.

The mirrored HTML is served from `public/framer.html` for `/` and all nested routes so deep links like `/blog` and `/legal/...` keep working offline.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
